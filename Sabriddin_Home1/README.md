# 🧠 Анализ выживаемости на Titanic: статистическое сравнение возраста пассажиров

## 📊 Цель анализа

В данном исследовании проводится углублённый статистический анализ различий в возрасте между выжившими и невыжившими мужчинами и женщинами на борту Титаника. Для этого используются:

- Тест Шапиро-Уилка (Shapiro-Wilk test) — для проверки нормальности распределений средних значений возраста.
- Тест Левена (Levene’s test) — для проверки равенства дисперсий между группами.
- T-тест Стьюдента — для определения, есть ли статистически значимая разница в среднем возрасте между группами.

## 📂 Описание данных

Используется датасет Titanic, содержащий поля:

- Sex: пол пассажира (male / female);
- Survived: статус выживания (1 — выжил, 0 — не выжил);
- Age: возраст пассажира (используются только ненулевые значения).

## 🔍 Группы сравнения

Созданы четыре группы:

- men_survived — мужчины, которые выжили;
- men_not_survived — мужчины, которые не выжили;
- women_survived — женщины, которые выжили;
- women_not_survived — женщины, которые не выжили.

## 🧪 Статистический анализ

### ✅ Тест на нормальность (Shapiro-Wilk)

Для каждой группы были созданы бутстрэп-выборки средних значений возраста (по 399 выборок по 50 элементов). Затем проверялась нормальность распределения этих средних значений:
